## 2. 小屏、缩放、输入与焦点

尺寸均为内容视口的逻辑像素，不能把物理屏幕除缩放后仍当原尺寸。窗口保留Windows系统标题栏/缩放及最小化能力，不强制最大化。默认内容目标1280×800；受工作区限制时自动缩入可用范围。支持视口宽≥640、高≥480；更小仍可滚动完成任务并提示“窗口较小，可放大以便对照”，不裁掉保存按钮或阻止启动。不得设置超过可用工作区的硬性最小窗体。

| 内容宽度/高度 | 布局规则 | 验收动作/期望 |
|---|---|---|
| ≥1200且高≥640 | 导航176；内容边距24；审核图/字段约各半，最小图320、字段360 | 图与字段同时可见；两个面板独立纵向滚动 |
| 900～1199 | 导航收为带可访问名称的56宽图标栏；边距16；审核图40%/字段60% | 图像可缩放拖动，不压缩表单标签；焦点不被导航遮挡 |
| 640～899或高<640 | 导航为可展开抽屉；边距12；审核仍保留并排“对照模式”，左右各最小280，中缝12 | 容器必要时横向滚动，字段可纵向滚动；另提供“原图/字段”切页便于放大，两种模式都可切回；并排不可完全取消 |
| 更小工作区/200%字体导致溢出 | 主区纵滚，审核容器按最小宽横滚；操作条在正常流中或可见吸底，预留等高底部空间 | Tab自动滚入焦点；任何金额/日期/确认按钮可到达，不截字导致无法操作 |

审核窄屏可拖分隔线且提供“恢复默认比例”；键盘聚焦分隔线后左右方向每次调5%，Home复位。图片面板有“适应窗口、100%、放大、缩小、重置定位”，图像自身平移不带走右侧字段；允许查看原图的每个区域，不能拿缩略图作唯一证据。

后续AC21必须分别执行：1366×768 100%（宽布局/收窄）；1366×768 125%（紧凑）；1366×768 150%（窄屏）；1920×1080 100%、150%、200%；并额外用内容视口640×480及1280×720验证。每项记录实际window.innerWidth/Height或等价内容尺寸、系统缩放、应用缩放、字体缩放，不能仅凭物理分辨率判断断点。应用缩放100/125/150/200%各验关键页面；100%起的系统与应用双重200%列压力用例，允许滚动但不丢操作。若某环境未测，报告该行未执行，不能称全面兼容。

全局Tab顺序：跳到主内容→导航→页面工具条→主体→操作区；Shift+Tab逆向。焦点2px蓝外框/2px间距且滚入视口；图标按钮有中文可访问名，错误/完成状态通过礼貌播报，阻断错误即时播报且不连发。原生按钮、单选组、表格语义优先；禁用原因是可聚焦相邻说明。

快捷键：Ctrl+N打开手工新增（密码框/模态对话框中不触发）；Ctrl+F聚焦当前列表搜索；Ctrl+Enter只在手工表单触发校验保存、审核中只打开确认预览，绝不越过最后批准；Esc依次关闭最上层弹层/固定提示/抽屉，不能取消已提交事务；Enter/Space激活当前按钮。中文输入法组合期间Enter不提交、不切页。不得用全局Delete直接删除交易、单键触发上传或批准。未保存修改离开时对话框“有未保存的修改”，按钮“保存并离开/放弃修改/继续编辑”；保存失败留原页。仅稍后离开且已有本地保存成功的审核字段才可无提示切走。

模态框焦点限制在框内，初始聚焦标题/说明或安全取消，关闭回触发器；字段错误提交后聚焦首个错误并保留其他输入。保存后回原列表锚点并播报结果；项被删除后聚焦相邻项或空态标题。搜索结果更新不抢输入焦点。长名列表省略时提供键盘可到达的完整文本/详情；金额不省略为误导数值，空间不足改行。

## 3. P01 记账列表与手工编辑（REQ-002～007/030；AC01～04/07）

布局：页头“记账”及“记一笔”；工具条含起止日期（界面显示含首尾，转换为契约exclusive end）、启用及停用分类多选、名称搜索、清空筛选、“已删除记录”；下方显示“符合筛选 N 笔 · ¥X”。日期组标题“今天/昨天 · M月D日 星期X”，其他同年“M月D日 星期X”，跨年“YYYY年M月D日 星期X”；每组右侧“支出 ¥X”，筛选中改成“筛选小计 ¥X”。同日跨页小计仍是整组筛选集，加载后续页合并组头。交易行图标/名称/类别/已知时刻或“时间未记录”/金额/更多操作；日期倒序且使用ARCH§6列表全序。

新增弹框：金额、日期、名称、分类四个必填项在前；时间开关默认“仅日期”（未知null），启用后HH:mm；商户、备注选填。手工日期默认今天，AI缺日期不能沿用此默认。金额输入无千分位、允许1或2位小数与整数；显示成功后统一两位。0.01～9,999,999.99元，拒绝空、0、负、科学计数、非数/三位小数；名称1～100码点、备注≤500；日期1900-01-01～9998-12-31。未来日期提示“所选日期在未来，当前周期统计尚不计入”，用户明确核实后才保存，不自动改今天。未选分类不可保存，不自动其他。

编辑沿用表单并带expectedVersion，显示只读来源及AI关联；停用旧类可原样保留但不能改选其他停用类。删除先确认“删除‘{名称}’？可在已删除记录中恢复。”按钮“保留/删除”；提交成功后从正式统计扣除，toast带“查看已删除记录”。恢复成功只恢复原笔，重复恢复不加笔。“已删除记录”始终标“此处金额不计入正式统计”，不复用正式总支出标签。

| 状态/操作 | 精确中文文案与期望 |
|---|---|
| 首次读取 | “正在读取本地账本…”；未知总额用占位，不闪出0当结果 |
| 真空账本 | “还没有支出，记下第一笔吧。”→“记一笔”；总额0.00 |
| 筛选无结果 | “没有符合条件的记录。”→“清空筛选”；不提示重建账本 |
| 校验不合法 | 金额：“请输入0.01～9,999,999.99元，最多两位小数。”；日期：“请选择有效的完整日期。”；名称：“请填写购买物或服务名称。”；分类：“请选择消费分类。” |
| 保存中/成功 | “正在保存…”只锁当前动作；成功“已保存1笔支出。”；没有收到持久化成功不关框 |
| VERSION_CONFLICT | “记录已被修改。请查看最新内容后重新保存。”；保留用户未提交输入供对照，刷新并人工合并，不覆盖 |
| SNAPSHOT_STALE | “账本已更新，正在重新读取列表。”；第一页重取，保留筛选/锚点，不能漏行重行 |
| DB_BUSY/空间不足 | “账本正忙，请稍后重试。”/“存储空间不足，尚未保存。请释放空间后重试。”；0半笔，保留表单 |
| 离线/取消 | “当前离线，手工记账可用。”；取消新增不写入，有修改先询问；已发保存不能靠关框声称取消 |

逐项验收用F01、F02、F03-S（顺序）、F03-I（隔离）；日期折叠不改总额，搜索“午餐”两笔33.50，清空后965.30；午夜/重获焦点重读相对日与统计，不用24小时差。

## 4. P02 分类（REQ-006/011；AC01/04/21/22）

布局：标题/新增/搜索；启用网格按ICON-MAP顺序，列数自适应（至少2列，每项中文常显）；单独停用区。点击卡片编辑名称、图标、排序，明确“保存/取消”；提供排序上移/下移按钮，不要求拖拽才能排序。记账/审核中的分类选择器是单选，方向键移动、Home/End首尾、Enter选择、Esc返回原输入。选择后归还焦点；“管理分类”不算候选类别。

正常新增“早餐”用本地餐具图标，出现新UUID类别；重命名餐饮不改历史ID；停用确认“停用后，新支出不可选用；历史记录和统计保留。”；其他按身份保护。loading“正在读取分类…”；搜索空“没有找到分类，可新建或清空搜索。”；停用区空“暂无停用分类”。重复名称：“分类名称已存在（含停用项），请换一个名称。”；空/超长：“请输入1～20字的分类名称。”；图标无效：“图标不可用，请选择本地图标。”；保护：“系统‘其他’分类不能停用。”（改名后说明仍以身份保护）。并发：“分类已变化，请刷新后重试。”；离线可维护本地分类，取消编辑无写入，存储失败保留原类。操作期望详见ICON-MAP§3。

## 5. P03 统计（REQ-007～011；AC03/05～07/21）

布局从上到下：周/月/年单选组→上一周期/当前周期标题（可开选择器）/下一周期/回到本周或本月或今年→分类筛选与范围说明→“总支出 ¥X”“日均支出 ¥Y · 分母N个自然日（含无消费日）”→折线→分类排行（类别、金额、百分比、比例条）。不承接记账页名称搜索，独立说明“仅按周期和所选分类统计正式未删除支出”。分类比例条以当前周期总额为基准；零总额全0.00%，不除零。停用类有历史额时保留。列表/统计各有独立筛选，不让隐藏筛选悄悄影响另一页。

周期：周一到周日7点，自然月28～31日点，自然年12月点；日期选择器禁止今天以后作为anchor，但可选择当前整月/整年。切换周/月/年使用原选定anchorDate，服务返回规范范围；回当前使用上海今天。当前“下一周期”禁用说明“已到当前周期”；最早可用边界不足整周报“该周超出支持日期范围，请选择其他周期”，不截成少于7点。跨月周显示完整日期区间、跨年含年份。日期点补0，未来点空心/虚线+“尚未到来”文本；未来点amount=0仅占位，无支出详情，未来正式交易仅在列表/显式CSV范围中可见。

日均历史÷完整周期自然日；当前÷周期开始到今天含今日的天数，年仍按天，不按12个月/消费日。以分的精确分子/自然日分母算元，显示半入四舍五入两位；占比同精确比值显示两位%。例F02历史9月965.30÷30=32.18；2026当前年截至10月20日分母293→3.29。同一次series/summary/排行/详情必须同scope/revision/today；变化时整组重取，旧结果不能混拼。

点提示：首行完整日/月，第二行“当日总支出/当月总支出 ¥X”置于Top3之前；日标题“最大3笔交易”，年/月点标题“前三消费分类”，下面按服务顺序列名及金额。不足三项显示实际项数，不补假行；无消费“暂无支出”；第四笔/第四类仍含于上方总额，底部可显示“仅列前三项，总额含全部支出”。同额日交易：已知时间优先、时刻降序、id ASCII升序（未知同额直接id）；月分类：全月聚合额降序、categoryId ASCII升序，不用类别显示名/用户排序作并列键。

鼠标hover即时临时提示，移到提示框内可继续阅读；单击点固定，点击另点切换、同点再次点或关闭按钮解除。图表一个Tab入口，左右选前后点、Home/End首尾，进入/移动即显示提示并播报日期/金额，Enter/Space固定，Esc解除，Tab离开。固定提示可经Tab进入关闭/查看明细按钮，无需鼠标；点击“查看明细”进对应日/月筛选列表但不修改周期统计口径。另有可展开数据表，与图同值可键盘逐行查看，不使31点全部占用Tab顺序。

提示框优先在点侧方留12px间距，碰边翻转并限制在可视工作区内（留8px）；不可遮住当前焦点、周期操作、审核/保存按钮。宽建议280～360、高不超过min(360,视口高的60%)，长名换行，内部可滚、金额完整。空间不足时在图下方正常流中显示固定详情卡，图点仍高亮且有连线/日期标识；缩放/滚动/切周期/开模态及时重新定位或关闭旧提示，不能悬在错误日期。提示需移入不消失、可Esc关闭、持续到用户移出或解除，不能计时自动消失导致读不完。

| 状态 | 文案/处理 |
|---|---|
| loading/切周期 | “正在计算本周期统计…”；旧卡若保留标“更新中”，禁用旧详情，不闪混合金额 |
| 空周期/空点 | 总额0.00、日均0.00、空点0及“暂无支出”；完整点数仍保留 |
| 未来点 | “尚未到来”；不显示“今天消费为0”或前三交易 |
| 断网 | “统计来自本地账本，离线可查看。”；无需API |
| 快照/午夜冲突 | “统计范围已更新，正在重新计算。”；同组重取，选中点有效则恢复 |
| 失败/汇总超限 | “统计暂未读取成功，请重试。”/“汇总金额超出支持范围，无法显示准确结果。”；不能显示0冒充成功 |
| 取消选择 | Esc关闭周期/分类弹层，保留已提交范围；统计本地查询不伪造可取消任务 |

逐项操作及数值见FIXTURES F02/F03全部分支，特别第四笔总额/Top3、同类跨日/跨月、空日期、并列、未来点和年分母。

## 6. P04 图片导入、预览与遮盖（REQ-012/014/015/018/021/022；AC09/12/14/21）

布局：上方“选择图片”与说明“JPEG/PNG/WebP，每批最多20张，每张不超过10MiB，最长边8192像素”；支持文件拖放，键盘通过原生选择器等价操作。左侧本批缩略图/逐文件校验结果，中央大图，右侧本地处理工具；底部“保存预处理/取消编辑”和“开始识别”。导入本身只在本地，不上传。超过整批20张提示重选，不静默只取前20；每图失败单列，其他成功图保留。超限图先拒绝，不能为了裁剪先不安全解码。

处理工具：适应窗口、100%、放大缩小、拖动；裁剪矩形可拖柄也可键盘输入x/y/宽/高（原像素整数）；保存裁剪后遮盖用裁剪后坐标，界面明确当前坐标系。遮盖为完全不透明填充、不是模糊/半透明，最多50个矩形；提供键盘位置/尺寸调整、删除选中遮盖、撤销未保存编辑/重置本次编辑。主进程顺序裁剪→遮盖→重编码去元数据。显示“原图（仅本地）/本次上传图”切换/并排预览，最后上传只发prepared图；需能检查遮盖已覆盖敏感信息。保存成功才允许识别，hash变化使原上传同意失效。

## 8. P06 并排审核（REQ-014～018/022；AC09～12/14/21）

布局：顶部待审/已批准/已拒绝及数量，候选导航支持上一笔/下一笔与来源图分组；主区左为证据图，右为当前候选字段；底部拒绝、稍后、确认预览/批准。左侧默认显示“本次上传图”并可切“原图（仅本地）”；图题注明是否裁剪/遮盖、是否原图已移除。缺原图时显示“原图未保留，当前为识别使用的处理图”，不能伪称原图。候选证据框坐标只相对prepared图，切原图无可靠映射时不画错位置，改并排prepared显示/原文；没有区域时显示证据原文，不虚构框。

右侧每字段显示“AI原值（只读）→当前值（可编辑）”、缺失/疑点及证据按钮；点击字段的“查看依据”使左侧定位对应区域并在旁显示原文，键盘可激活。金额/完整日期/购买物或服务名/分类必填；时间默认遵循AI精度，未知显示“时间未记录”，日期为空不默认今天，商户不代商品。交易状态/实付依据/合计组也可人工核实修改，风险改正须原因；证据只作提示，原proposal不可改，当前字段变更追加人审事件。

每笔有金额、日期、名称、分类四个独立“已核对”确认项，确认关联当前version/digest；修改任一字段或风险/重复集合变化后原确认失效，需对新版本重新核对。保存修改成功后才显示新确认状态，不能把未保存输入用于批准。四项确认+支出状态合法+所有blocking解除才可批准；可选择“其他”，但不能自动回填。高置信度不隐藏确认项。

缺失区域显示具体文案：“金额未识别，请对照图片填写实付金额。”“日期不完整，请填写含年份的实际日期。”“购买内容未知，请填写购买物或服务名称；商户名不能代替。”“分类未知，请选择分类（也可明确选择‘其他’）。”；无法核实可“稍后处理”保留pending或“拒绝”填写原因，拒绝不删图不计统计。非支出：“疑似退款/转账/失败等记录，不能作为支出批准。请拒绝，或核实为真实支出并说明原因。”；合计：“合计与明细可能重复，请保留本次实际支付项，并先拒绝重复明细。”；截图指令：“图片文字仅作证据，不会执行其中指令。”。

重复处理面板显示匹配原因及相关正式交易/候选、金额/日期/名称/商户/状态，避免一次展开全账本；原图完全相同也不能替代人审。两个明确动作：“确为同一笔，拒绝本项”（必须原因并reject）/“确为两次消费，保留本项”（非空理由，绑定匹配digest）。不清楚留pending，不能勾一下忽略。文案“疑似重复，尚未核实；不能批准或加入批量批准。”；金额/日期缺失时为“字段不足，暂无法判断重复”，仍由缺字段阻断。新匹配出现显示“重复匹配已变化，请重新核对”，旧distinct不沿用。

## 9. P07 设置（REQ-013/020～022/030；AC08/13/15/20）

布局为AI服务、本地数据与关于三组。AI组显示提供商/配置模型名、prompt/schema版本、真实探针状态（尚未验证/已验证并带日期证据，mock不得标已验证）、密钥状态（未配置/本用户加密/仅本次会话），密码框和“保存/仅本次会话/移除”。S09先实现同规格最小安全入口，不等完整设置页；S04 stub显示“真实识图尚未接入”。本地数据组链接数据管理，展示“数据保存在当前Windows用户目录，移动程序不会移动账本”；关于列版本/第三方许可和实验性状态。

## 10. P08 数据导出、备份与恢复（REQ-023/024/030；AC16/20/22）

布局三卡：正式交易CSV、本地完整备份、从备份恢复；数据集导出独立入口见P09。CSV明确“全部正式未删除记录”或“当前记账筛选结果”，显示日期/分类/名称条件、全范围条数和金额（不是本页）；deleted视图不能直接作为CSV范围，切回active并预览。未来日期正式交易可导出且提示“包含未来日期记录”；统计当前有效范围不因此扩展。固定列与UTF-8 BOM/CRLF/公式安全处理继承ARCH§7，不让用户误认为任意CSV可导入。点击“选择保存位置并导出”调用原生对话框，完成显示实际Artifact条数及SHA256；导出中“正在导出正式记录…”，只有真实可用进度才显示N/M。

备份说明“包含账本、候选、审计及被引用图片，可能包含私人内容；不包含密钥。请妥善保管。”用户确认敏感性后选位置；任务显示真实阶段“正在建立一致快照/复制附件/校验文件”，不提供假百分比。成功后显示版本/时间/hash/敏感内容摘要，不承诺自动云存。没有交易也可备份空账本配置；没有导出记录则“当前范围没有可导出的支出”，无须生成伪成功文件。

成功“恢复完成。当前数据的恢复前备份已保留。”；显示preRestoreBackup标识与档案hash，重新读默认账本/epoch/统计/本机key状态，历史识图/数据集同意分别失效，提示“恢复后再次上传或导出数据集前，需要重新同意”。processing历史任务为INTERRUPTED，queued等重确认，不自动补费。pre_restore及旧generation保留到用户另行清理，不自动删除。程序正常重启不等于恢复，不自动使同意全部失效。

| 损坏/hash/不支持版本 | “备份校验失败，当前账本未更改。请换一个完整备份。”；“备份来自更新版本，请用兼容版本打开。”，不能建空库顶替 |
| 空间不足/占用 | “无法完成备份，当前账本未更改。请检查空间和文件占用后重试。”；pre_restore失败绝不切换 |
| 恢复失败/中断 | “恢复未完成，已保留原账本和恢复前备份。请查看恢复结果后重试。”；只在主进程已确认旧active完好时这样说，否则“恢复状态待确认，已停止写入。请按恢复指引处理。” |
| 维护/多实例 | “账本正在维护，完成后可继续操作。”/“此账本已在另一个窗口运行，请使用已有窗口。”；不并发写库 |
| 导出失败/文件已移除 | “导出未完成，请重新选择位置后重试。”/“此前导出的文件已移走或删除，可重新导出。”；成功收据不凭空重建文件 |
| 离线/超时/冲突 | “数据导出与恢复在本地完成，无需联网。”；本地慢任务不套90秒网络计时器；预览过期或数据变化“备份预览已失效，请重新检查后恢复。” |

F05规定具体操作、全部范围与筛选金额、坏档案/故障期望。完整备份不允许删附件仍自称完整，恢复不恢复已删除的外部CSV文件。

## 11. P09 数据集与评测入口（既定范围的交互预留）

REQ-025～027；AC17～19。数据管理下“样本与评测”独立页：授权/许可/脱敏/标签/复核、重复组/split、版本/test锁、评测与报告分区；展示真实/合成计数，不将正式审核等同标签真值。默认“未加入数据集”，同意识图后此状态不变；“同意本图纳入数据集”有独立用途及许可说明，仍需主动登记/标注/复核。标签可unknown/null，不能猜；锁test后修改走新版本、不原地改旧快照。撤回对话框说明停止后续导出/评测、不能收回已导出副本、不删除合法账本引用。

导出先选择版本/用途/完整组范围/是否含图，展示实际计数/parent/subset范围及独立同意；撤回样本阻断整次导出，不静默删样本还用旧版本hash。评测选择framework/quality、provider/prompt/seed，DeepSeek逐图上传另需同意/费用，显示真实processed/failed/total、partial、合成/真实分母及unknown限制；不把API调用、纠错或提示词变更称训练。首版训练提交与查询明确“不支持模型训练提交（UNSUPPORTED）”，无远端任务/假权重/进度。

状态文案：“尚无已授权样本。”“正在读取样本版本…”；“缺少许可或脱敏复核，暂不能导出。”“此版本含已撤回样本，请建立新版本后重试。”“test版本已锁定，不能原地修改。”“评测规范尚未就绪，当前仅检查结构，不代表识别质量。”“已取消评测，已完成部分仅供参考。”；网络失败保留本地标签，重试收费需新同意；版本冲突刷新再人工合并；取消导出对话框不出文件，取消评测先失效generation。S12补标注/指标/划分细则，S13实现；不能在S03编造质量门槛通过。
